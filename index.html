qwennie🐩

a 78,672 parameter chat transformer that lives entirely in css. real attention, rope, rmsnorm, swiglu, int8 matmuls, a kv cache made of inherited custom properties — and not one line of javascript. pick a message and she replies in a single style pass.

heads up: she only re-computes properly in chromium. the first reply below is correct in every engine, but picking a different message won't update it right in this browser — they disagree about invalidating a custom property chain 36 levels deep. the readme has the gory version.
this browser is missing some css math (mod, sign, abs, exp, sqrt, @property, or container style queries). qwennie needs chromium 138+, safari 18+, or firefox 151+ to think. she is not mad, just quiet.

she is a real decoder-only transformer: 2 layers, 2 heads, d=48, context 36. every token is one level of dom nesting. attention is unrolled per position — o(t²) in stylesheet bytes — and softmax runs on css exp(). her matmul weights are int8 in weights.json, dequantized into calc() at build time. she was trained from scratch on a tiny original corpus; the name is a homage, no actual qwen weights are involved (they would be several gigabytes of stylesheet, and the browser would simply pass away).

her big sister yipsy babbles prose next door. wtfpup licensed.
